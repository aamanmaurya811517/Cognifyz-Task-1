# Cognifyz Task 1 – Registration Page

A simple and responsive registration page developed as part of the **Cognifyz Technologies Full Stack Development Internship**.

## 📌 Project Overview

This project demonstrates basic server-side development using Node.js, Express.js, and EJS. Users can enter their name and email address, accept the terms and conditions, and submit the registration form to receive a success message.

## ✨ Features

- Responsive registration page
- User name and email input fields
- Terms and conditions checkbox
- Server-side form handling
- Form validation
- Dynamic HTML rendering using EJS
- Registration success message
- Custom styling with CSS

## 🛠️ Technologies Used

- **HTML5** – Page structure
- **CSS3** – Styling and responsive layout
- **Node.js** – JavaScript runtime
- **Express.js** – Web server and routing
- **EJS** – Server-side HTML rendering

## ⚙️ Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/aamanmaurya811517/Cognifyz-Task-1.git
```

### 2. Navigate to the project folder

```bash
cd Cognifyz-Task-1
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the server

```bash
node server.js
```

### 5. Open the application

Visit the following URL in your browser:

http://localhost:3000

## 📖 How It Works

1. Open the registration page.
2. Enter your full name and email address.
3. Accept the terms and conditions.
4. Click the **Sign Up** button.
5. The Express server validates the submitted information.
6. EJS dynamically renders the registration success page.
